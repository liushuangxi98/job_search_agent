# 求职决策 Agent：已批准的前后端实现计划

用户于 2026-10-31 明确要求实施本计划。执行状态和验证结果见 `docs/实施与验收记录.md`；设计依据为 `docs/superpowers/specs/2026-10-30-求职决策智能体设计与分工.md`。

## 目标与边界

交付本机可运行的原生前端、FastAPI、MySQL 存取、Agent 接入接口和明确标注的固定联调样例。用户亲手实现全部 Agent 代码，包括模型、文档解析、OCR、高德、RAG、评分、面试决策、记忆和评测。

样例模式明确显示模拟数据；真实模式未接入时明确报错，不回退到样例。前后端只接收、保存和展示评分结果，不编写业务评分算法。

## 技术与数据

Python 3.13、FastAPI、同步 SQLAlchemy 2.x、PyMySQL，项目独立虚拟环境。FastAPI 同时提供页面与 API，默认监听 `127.0.0.1:8000`。

MySQL 保存当前画像和条件、确认状态与修订号、上传资料元数据、岗位及来源关系、题目、已确认记忆，以及已完成报告和输入快照。原始文件在项目目录。运行、聊天上下文、待确认提案和未完成面试只在内存。

提供 `/api/profile`、`/api/preferences`、`/api/documents`、`/api/jobs`、`/api/knowledge/questions`、`/api/memories`、`/api/reports`、`/api/runs` 和 `/api/health`。

金额为元/月，通勤为分钟，未知为 null。报告读取自身快照。初始化只创建项目库和缺失表，不清空记录；数据库不可用明确报错，不切换其他数据库。

## Agent 接入与界面

入口集中在 `backend/agent_gateway.py`，约定 `async handle(command, services, emit) -> AgentResponse`。命令包含动作、运行ID、当前对象与输入；服务提供受控文件读取和普通数据库存取；emit发送事件。

动作覆盖简历、岗位提取、题库、评估、面试、聊天和人工补充。运行状态为 running、needs_input、completed、partial、failed。应用不实现 LangGraph 或业务决策；固定样例与真实入口使用相同契约。

界面使用中文浅色桌面风格、原生 HTML/CSS/JavaScript，无构建工具。六个hash路由视图为简历、条件、岗位池、评估、报告、题库。岗位详情为抽屉，面试为全屏，聊天贯穿各步骤并关联当前对象。

前端每秒轮询新增事件，等待输入或结束时停止。统一处理加载、空数据、错误和模拟标识。修改提案确认才保存。

图片逐张上传，单张8MiB，简历和MD单文件16MiB；服务端检查实际请求字节数，413显示失败且不自动重试。

## 实施任务

1. 运行基础与MySQL存取：依赖、环境模板、初始化和Windows启动脚本，验证中文、JSON、修改与重启读取。
2. Agent契约与内存运行容器：固定样例覆盖成功、缺资料、等待确认、部分结果和失败，真实模式不回退。
3. 资料与岗位界面：上传、画像确认、条件编辑、岗位管理、题库列表及来源查看。
4. 评估、报告、面试和聊天：事件、人工补充、报告导出、修改确认，样例不分析实际输入。
5. 联调与说明：启动、接口、接入方式、常见问题；完成独立代码审查与子代理视觉验收。

## 验证

- 隔离MySQL测试库中的CRUD、事务、重启读取。
- 非法输入、未知文件ID、上传限制与失败清理。
- 人工补充、重复确认、拒绝修改、修订冲突。
- 重启后运行失效但报告仍在。
- 模拟/真实模式区分及事件脱敏。
- 六视图、抽屉、后退、全屏面试、聊天。

视觉验收必须委派子代理，父线程仅接收文字，一次必要区域一张图，完成后关闭子代理。不得用样例验证结论宣称真实Agent能力完成。

## 实施条件

用户本地填写 `.env` 的 MySQL 连接，不在聊天中提供密码。前后端阶段不需模型、高德密钥，不安装Agent专用依赖，不创建或填充用户Agent实现文件。
